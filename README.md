## Brief One-Line Summary

Interactive Excel dashboard built to analyze 10K sales transactions, revenue, profitability, products, customers, regions, sales channels, and salesperson performance across 2024–2026.

---

## Overview

This project transforms raw sales transaction data into actionable business insights using Microsoft Excel.

The dashboard provides a centralized view of sales performance, profitability, regional performance, customer segments, product performance, sales channels, and salesperson contribution.

The objective is to move from raw transactional data to clear business questions, measurable KPIs, and decision-oriented insights.

## How to Run This Project

1. Clone or download this repository.

2. Open the Excel workbook:

   `Sales_Performance_Dashboard.xlsx`

3. Navigate to the `Sales_Data` sheet to explore the raw transaction data.

4. Review the PivotTables and analytical calculations.

5. Open the `Dashboard` sheet.

6. Use the available slicers and timeline filters to interact with the dashboard.

7. Explore the business questions and corresponding insights.

## Results and Conclusion

The dashboard converts 10,000 transactional records into a management-oriented analytical view.

The analysis shows that **South** is the strongest region, **Technology** is the dominant category, **Consumer** customers contribute the largest share of revenue, and **Online** is the strongest sales channel.

The dashboard also highlights the difference between sales performance and profitability, helping identify areas where high sales volume may not necessarily translate into strong profit.

Overall, the project demonstrates how Excel can be used to move from:

**Raw Data → Data Analysis → KPIs → Business Questions → Insights → Decisions**
